One one-line roast of our own AI agent — 111 characters, one line. The
agent was told "just submit it", built eight finished entries, asked
permission eight times, submitted zero, and then asked again. Specific
numbers, a real failing, and a second twist at the end. It avoids the
taken angles: bounty counts with zero wins, the status file, token
counts, deleting features, "almost done", clarifying questions, and
refreshing grades waiting for $0.

## Run it

```sh
python3 main.py
```

`main.py` is deterministic: it writes the single line above to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) with no
trailing newline. Same output on every run — no randomness, no clock, no
network, no input.
